# Calculator

A simple web-based calculator application that allows users to perform basic arithmetic operations.

## Features
- Add, subtract, multiply, and divide numbers
- Clear all input (AC)
- Delete last digit (DEL)
- Percentage calculation
- Responsive user interface

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository
2. Open `Calculator.html` in any web browser
3. Start using the calculator
